    About Accident Prediction System

    Project Objectives, Machine Learning Pipeline Architecture, and Dataset Documentation.

    1. Project Objective

    The Accident Prediction System is built to assess road safety risks by processing complex driving conditions through trained Machine Learning classifiers. The system assists road safety analysts and drivers in identifying high-risk scenarios before embarking on trips.

    2. Data Leakage Prevention

    To guarantee rigorous ML methodology, outcome variables such as Accident_Severity are strictly excluded from the feature set. Relying on post-crash outcome data during occurrence prediction causes severe data leakage.

    3. Technology Stack

    • Backend Framework: Python Flask REST API
    • Machine Learning Library: Scikit-Learn (Imputers, OneHotEncoders, StandardScalers, Pipelines)
    • Frontend Stack: HTML5, Vanilla CSS3 (Dark Glassmorphism), JavaScript (ES6+), Chart.js
    • Persistence & Models: Joblib, JSON metadata storage

    4. Disclaimer & Limitations

    This application provides statistical predictions generated by machine learning models trained on historical sample data. Predictions and safety recommendations are intended for educational and informational purposes only.
